# Subler Neo 1.0 (4)

Det godkendte nye Composer-ikon er nu indbygget i appen. Ikonet har en mindre tonet undertekstplade, synlig lagdybde, skrå filmramme og metallisk pen. Kildeprojektet har 12 lag i 4 grupper.

Release-bygning, identitetskontrol og alle 15 pakketests bestod. Den udleverede ZIP blev pakket ud igen; streng signaturkontrol, buildnummer, ikonnavn, syv arm64-programmer/biblioteker og arkivets kontrolsum er verificeret. Manuel opstart viste det nye ikon og version 1.0 (4) i Om-vinduet.

Denne version ændrer ikonressourcer og buildnummer. Konverteringskoden er den samme som i build 3; de 38 lyd-/tidslinjetests er ikke kørt igen for denne ikonændring. Se KODEGENNEMGANG-3.md for de tidligere kode- og lydrettelser samt deres dækningsgrænser.

Apple Silicon, macOS 13 eller nyere. Lokalt signeret testudgave, ikke notariseret; egen automatisk opdatering er stadig deaktiveret. Kildekode og det godkendte ikon vedligeholdes på grenen `neo/apple-silicon` i NickLauritzenDK/Subler.
